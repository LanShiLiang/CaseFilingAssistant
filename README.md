# Case Filing Assistant

面向中国大陆用户的法律文书辅助生成项目。首期 MVP 聚焦于：根据用户上传的证据、调解书、判决书等材料，提取并由用户确认案件事实，生成可人工审阅的申请强制执行材料包。

## 产品边界

- 仅生成草稿和可下载材料，不自动向法院提交、立案、缴费或送达。
- 全国性法律、司法解释和最高人民法院规则作为基础规则。
- 地方法院差异通过可配置规则包处理，并要求用户逐项确认。
- 所有事实和生成字段应可追溯到用户材料或用户填写内容。
- 身份证号、住址、电话、账户等敏感信息不得进入代码仓库、日志或公开测试数据。

## 安全说明

不得把真实案件材料、身份证件、联系方式、银行账户、签名、印章、OCR 中间结果或生成的案件文书提交到 Git。测试数据必须使用完全虚构的信息。
